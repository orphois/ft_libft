## Description:
I created this library - its 43 functions - to have a toolkit for future projects and to study how specific functions behave, their uses and limitations.

## Instructions:
Use the "make" command while the library is your working directory. This will compile all the functions and render them able to be used.

## Resources:
The functions were tested using the "libfttester". I mainly used VSCode and also Vim to some lesser extent (for the headers). I learned, how to exactly shape these functions by trial and error, reading the manuals carefully, by seeking help from some websites (w3shools and cppreference), by engaging with colleges and last but not least from Chat-gpt.
AI was used in one case (ft_split) to help comply with norminette rules and in some other cases to test the code.

## Detailed description:
The functions in this library check characters, they modify strings and pointers, the allocation of bytes. It implements a linked list and provides ways to handle it, like adding nodes, deleting them, counting them. Some functions also operate using from the user provided code, creating an opportunity to alter mass quantities of data in one step.
